# love-proposal-website
A romantic proposal website with a playful twist

## Quick start
1. Open `index.html` in a browser, or
2. Run a local static server from the project folder:
   ```bash
   python3 -m http.server 8000
   ```
3. Visit `http://localhost:8000`

This is a simple single-page romantic proposal website built with HTML, CSS, and JavaScript.
